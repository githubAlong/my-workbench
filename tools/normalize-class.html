年级班级整理

把历史数据里混着的「高二5班 / 高二(5)班 / 5」统一成 年级 = 高二、班级 = 5班。

整理规则

· 年级字段去掉「年级」二字、括号和空格：高二年级 → 高二

· 班级字段剥掉年级前缀，统一成「N班」：高二5班 / 高二(5)班 / 05 → 5班

· 只有班级没有年级的表（调课、奖惩、作业记录等），把年级写进班级值前：5班 → 高二5班，信息不丢

· 只改年级和班级两个字段，其余字段一字不动

# 我的工作台（公网版）

单文件应用 index.html，由 WorkBuddy 发布到 GitHub Pages。

课表页提供「更新2026秋季信息课表」入口。每次更新都会先要求确认，并在当前浏览器本机保存已有课程和节次的快照；普通课表导入也会先确认并备份。该模板只包含班级、星期、节次和科目，不包含账号、旧课表或浏览器本地数据。

## 登录

仅支持手机号账号：注册时填写手机号和密码，不需要短信验证码；登录使用手机号和密码。要让免验证码注册成功，请在 Supabase → Authentication → Sign In / Providers → Phone 中开启自动确认（关闭 Phone confirmations）。忘记密码仍可通过短信验证码重置，这与注册流程分开。

本次认证升级会在每个浏览器中一次性清除旧本机账号、工作台本地数据、登录令牌及云同步绑定，避免旧数据再次导入。Supabase 云端账号和云端数据不会被删除；本地数据清除后如需恢复，请由用户自行从已有备份恢复。

# 我的工作台（公网版）

单文件应用 index.html，由 WorkBuddy 发布到 GitHub Pages。

课表页提供「更新2026秋季信息课表」入口。每次更新都会先要求确认，并在当前浏览器本机保存已有课程和节次的快照；普通课表导入也会先确认并备份。该模板只包含班级、星期、节次和科目，不包含账号、旧课表或浏览器本地数据。

## 登录

新账号使用手机号注册，可通过手机号和密码或短信验证码登录；忘记密码时可用短信验证码重置。注册短信验证由 Supabase 的 Phone Confirmation 设置控制。以上功能依赖 Supabase Auth 的 Phone Provider 和已配置的短信服务。已有账号保留旧账号/邮箱登录入口；已连接云端的邮箱账号可在「我的 → 云同步」绑定手机号并保留原云端身份，旧本机账号不支持短信找回。
